# Curso de C#

Study repository with console applications written while learning C# and object-oriented programming.

![C#](https://img.shields.io/badge/C%23-512BD4?style=for-the-badge&logo=csharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

## Topics covered

- Input and output, conditional structures and enums
- Constructors, overloading, inheritance and interfaces
- Exceptions and file handling
- Collections (Dictionary) and LINQ
- Small projects such as a car rental system

Each folder is an independent console project that can be opened in Visual Studio and run on its own.
