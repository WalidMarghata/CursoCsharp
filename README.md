# Curso de C#

Study repository with console applications written while learning C# and object-oriented programming: constructors and overloading, collections such as Dictionary, and general language exercises.

![C#](https://img.shields.io/badge/C%23-512BD4?style=for-the-badge&logo=csharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

Each folder is an independent console project that can be opened in Visual Studio and run on its own.
